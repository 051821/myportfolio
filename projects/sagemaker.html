Overview

This project demonstrates a production-style, cloud-based machine learning workflow for predicting heart disease using AWS SageMaker. It covers the complete lifecycle of an ML project — from data ingestion and preprocessing to model training, evaluation, and artifact storage.

The focus of the project is not just model accuracy, but also on building a scalable and reproducible ML pipeline using AWS-managed services.

Problem Statement

Healthcare datasets often contain a mix of numerical and categorical features, missing values, and varying data scales.

The challenge is to design a cloud-based ML pipeline that reliably handles preprocessing, model training, and evaluation while remaining scalable and suitable for real-world deployment scenarios.

Data Pipeline (Amazon S3)

  • Programmatically created and managed Amazon S3 buckets using Boto3
  • Uploaded raw CSV datasets to S3 for centralized storage
  • Loaded datasets directly from S3 into SageMaker notebooks
  • Performed train–test splits and stored processed datasets back in S3
  • Ensured consistent and reproducible data access across experiments

Preprocessing & Feature Engineering

  • Separated numerical and categorical features using ColumnTransformer
  • Applied One-Hot Encoding to categorical variables
  • Scaled numerical features using StandardScaler
  • Handled missing values using SimpleImputer
  • Built a unified Scikit-learn Pipeline to prevent data leakage

Modeling & Training

A Random Forest classifier was trained as the primary model due to its robustness and ability to handle non-linear feature interactions.

  • Trained and evaluated a Random Forest classifier
  • Used SageMaker-managed infrastructure for training execution
  • Experimented with SageMaker’s built-in Linear Learner for comparison
  • Stored trained model artifacts and outputs in Amazon S3

Evaluation Strategy

Model performance was evaluated using standard classification metrics, including accuracy and a detailed classification report.

This evaluation helped validate the model’s generalization performance on unseen test data, which is critical in healthcare-related prediction tasks.

AWS SageMaker Integration

  • Configured IAM execution roles for secure SageMaker access
  • Used the SageMaker SDK for managed ML workflows
  • Leveraged SageMaker notebooks for experimentation
  • Utilized S3 for versioned storage of datasets and model artifacts
