AWS SageMaker – Heart Disease Prediction

End-to-end machine learning pipeline on AWS using SageMaker, S3, and Scikit-learn

View GitHub

Overview

This project demonstrates a cloud-based, end-to-end machine learning workflow for heart disease prediction using AWS SageMaker. It covers data ingestion from Amazon S3, preprocessing, model training, evaluation, and experimentation with both Scikit-learn pipelines and SageMaker’s built-in algorithms.

Problem Statement

Medical datasets often contain a mix of numerical and categorical features. Building a scalable ML pipeline that handles preprocessing, training, and evaluation in a cloud environment is essential for real-world healthcare applications.

Data Pipeline

  • Programmatically created and managed S3 buckets using Boto3
  • Uploaded and loaded CSV datasets directly from Amazon S3
  • Performed train–test split and stored processed data back into S3
  • Ensured reproducible data access for training workflows

Preprocessing & Modeling

  • Handled categorical features using One-Hot Encoding
  • Scaled numerical features using StandardScaler
  • Imputed missing values using SimpleImputer
  • Built a Scikit-learn Pipeline with ColumnTransformer
  • Trained a Random Forest classifier for prediction

Evaluation

Model performance was evaluated using accuracy and a detailed classification report to assess predictions on unseen test data.

AWS SageMaker Integration

  • Configured AWS execution roles and SageMaker environment
  • Used SageMaker SDK for managed ML experimentation
  • Initialized SageMaker Linear Learner for binary classification
  • Stored trained model artifacts and outputs in Amazon S3

Tech Stack

Python · AWS SageMaker · Amazon S3 · Boto3 · Pandas · Scikit-learn · Random Forest · Linear Learner

What This Project Demonstrates

  • Hands-on experience with AWS SageMaker workflows
  • Cloud-based data handling and model training
  • End-to-end ML pipeline design
  • Feature engineering and preprocessing best practices
  • Applying ML models in a healthcare prediction context
