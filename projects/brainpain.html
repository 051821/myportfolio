BrainPain Generator 😭→🧠

A local, fully offline RAG-powered MCQ generator built with Streamlit and Ollama

View GitHub

Overview

BrainPain Generator is a Retrieval-Augmented Generation (RAG) based quiz system that generates challenging MCQs from any uploaded PDF. The application runs fully offline and combines semantic retrieval, keyword matching, and constrained LLM prompting to produce grounded, high-quality questions with explanations.

How It Works

  • PDF is read and split into overlapping chunks
  • Chunks are embedded and indexed using FAISS
  • Hybrid search retrieves relevant context
  • Context is summarized to reduce token usage
  • LLM generates MCQs using strict RAG prompting
  • One-shot explanations generated for all questions

Key Features

  • Fully offline RAG pipeline using Ollama
  • Hybrid search (vector similarity + keyword matching)
  • Strict MCQ formatting with retry and fallback logic
  • One-line explanations generated in a single LLM call
  • Rule-based MCQ parsing with error tolerance
  • Intentionally fun and savage user interface

Algorithms & Techniques

  • Recursive Character Text Splitting
  • Semantic embeddings using nomic-embed-text
  • FAISS Approximate Nearest Neighbor search
  • Hybrid retrieval to reduce hallucinations
  • LLM-driven context summarization
  • Constraint-based prompt engineering
  • Rule-based parsing and auto-repair mechanisms

Tech Stack

Python · Streamlit · LangChain · Ollama · FAISS · PyMuPDF · nomic-embed-text · LLaMA / DeepSeek models

What This Project Demonstrates

  • Hybrid retrieval strategies for grounded generation
  • Robust handling of LLM failures
