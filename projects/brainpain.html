Overview

BrainPain Generator is a Retrieval-Augmented Generation (RAG) based quiz system that generates challenging MCQs from uploaded PDFs. The application runs fully offline and combines semantic retrieval, keyword matching, and constrained prompting to produce grounded questions with explanations.

How It Works

  • PDF is parsed and split into overlapping chunks
  • Chunks are embedded and indexed using FAISS
  • Hybrid retrieval fetches relevant context
  • Context is summarized to reduce token usage
  • LLM generates MCQs with strict formatting rules
  • One-shot explanations generated for all questions

Key Features

  • Fully offline RAG pipeline using Ollama
  • Hybrid search (vector + keyword)
  • Strict MCQ schema with retries & fallback
  • Single-call explanation generation
  • Rule-based parsing with auto-repair
  • Intentionally fun and brutal UX

Algorithms & Techniques

  • Recursive character text splitting
  • Semantic embeddings using nomic-embed-text
  • FAISS approximate nearest neighbor search
  • Hybrid retrieval to reduce hallucinations
  • Constraint-based prompt engineering
  • Rule-driven parsing and validation
