Overview

The Facebook Ads Intelligence System is designed to automate performance analysis for digital marketing campaigns using a multi-agent AI architecture. Instead of relying on manual inspection of dashboards, the system ingests ad metrics, detects anomalies such as ROAS or CTR drops, and produces structured, explainable insights.

Each insight is validated using deterministic checks to reduce hallucinations and ensure recommendations are grounded in real data — making the system suitable for production use.

Problem Statement

Marketing teams spend significant time manually analyzing Facebook Ads dashboards to understand why performance changes occur. This process is:

  • Time-consuming and repetitive
  • Highly subjective and analyst-dependent
  • Prone to missing hidden correlations
  • Difficult to standardize across teams

The goal of this project was to build an AI system that can replicate and standardize analyst reasoning while maintaining reliability and explainability.

Solution Architecture

I designed a modular multi-agent system where each agent is responsible for a well-defined task in the analysis pipeline. This separation of concerns improves scalability, interpretability, and fault tolerance.

  • Planner Agent — Determines the analysis strategy based on available data
  • Data Agent — Performs schema validation, sanity checks, and data drift detection
  • Insight Agent — Uses LLM reasoning to generate hypotheses explaining metric changes
  • Evaluation Agent — Validates hypotheses using before–after numerical comparisons
  • Creative Agent — Suggests creative or targeting optimizations

Key Technical Highlights

  • LLM output validation with schema enforcement and auto-repair
  • Retry logic with exponential backoff for API robustness
  • Data drift detection to prevent misleading insights
  • Deterministic evaluation mode for CI/CD testing
  • Structured logging, metrics, and confidence scoring

Outputs Generated

The system produces machine-readable and human-readable outputs:

  • insights.json — Validated insight hypotheses with confidence scores
  • creatives.json — Creative and targeting recommendations
  • report.md — Executive summary with actionable steps
