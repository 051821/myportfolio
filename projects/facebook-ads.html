Facebook Ads Intelligence System

Production-ready multi-agent AI system for automated Facebook Ads performance analysis

View GitHub

Overview

This project is a production-grade multi-agent AI system that analyzes Facebook Ads performance similar to a human marketing analyst. It automatically diagnoses issues such as ROAS or CTR drops and generates validated, actionable recommendations.

Problem Statement

Manual ad performance analysis is time-consuming, inconsistent, and often subjective. Marketing teams struggle to identify the real drivers behind performance drops and convert raw metrics into actionable insights.

Solution Architecture

I designed a multi-agent architecture where each agent performs a specialized role, combining LLM-based reasoning with deterministic validation for reliability.

  • Planner Agent: Builds the analysis strategy
  • Data Agent: Validates data and detects drift
  • Insight Agent: Generates hypotheses using LLMs
  • Evaluation Agent: Verifies insights with metrics
  • Creative Agent: Recommends creative improvements

Key Technical Highlights

  • Robust JSON parsing with auto-repair for malformed LLM outputs
  • Retry logic with exponential backoff and fallback strategies
  • Schema validation and data drift detection
  • Deterministic test mode with full CI/CD pipeline
  • Structured logging, metrics, and confidence scoring

Outputs Generated

  • insights.json – Validated hypotheses with confidence scores
  • creatives.json – Creative recommendations
  • report.md – Executive summary with actions

Tech Stack

Python 3.12 · LangChain · OpenAI / Ollama · Pandas · Loguru · PyTest · Ruff · GitHub Actions (CI/CD)
