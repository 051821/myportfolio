Iterative Human Feedback for Generative Models

Improving GPT-2 text generation using iterative human and automatic feedback

View GitHub

Overview

This project explores an Iterative Human Feedback (IHF) framework to improve the quality of text generated by generative language models. Using GPT-2 as the base model, the system refines product descriptions over multiple iterations by combining automatic evaluation metrics with manual human ratings.

Objective

The goal is to demonstrate how iterative feedback loops can progressively enhance generative model outputs without full model fine-tuning, by rewarding better generations using both quantitative metrics and human judgment.

Approach

  • Generate product descriptions using a pre-trained GPT-2 model
  • Evaluate outputs using BLEU and ROUGE-L metrics
  • Collect manual human ratings for each generation
  • Combine automatic scores and human feedback into a unified reward
  • Iteratively refine generation quality across multiple iterations

Evaluation Strategy

The reward function balances human judgment with automatic evaluation metrics:

Combined Reward = 0.7 × (Manual Score / 10) + 0.3 × (BLEU + ROUGE-L) / 2

Key Features

  • Automatic evaluation using BLEU and ROUGE-L
  • Manual rating-based feedback loop
  • Visualization of performance trends across iterations
  • Adaptable to multiple text generation datasets
  • Clear demonstration of human-in-the-loop learning

Dataset

The system operates on CSV-based datasets containing product names, key features, and reference descriptions (e.g., Amazon product datasets).

Clarification on Reinforcement Learning

This project does not implement full reinforcement learning algorithms such as PPO or policy-gradient optimization. Instead, it demonstrates an RL-inspired iterative feedback framework where generations are evaluated using automatic metrics and human ratings, and improvements are guided through reward-based selection.

Tech Stack

Python · GPT-2 (Transformers) · PyTorch · NLTK · Pandas · Matplotlib · ROUGE-Score

What This Project Demonstrates

  • Human-in-the-loop learning in generative models
  • Understanding of text generation evaluation metrics
  • Iterative refinement of model outputs
  • Bridging automatic scoring with human judgment
  • Foundational concepts behind RLHF-style approaches
