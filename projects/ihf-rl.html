Iterative Human Feedback for Generative Models

An RL-inspired human-in-the-loop framework that progressively improves GPT-2 text generation using iterative feedback, evaluation metrics, and reward-based refinement.

Overview

This project investigates how iterative human feedback can be used to improve the quality of text generated by large language models without performing full reinforcement learning or expensive fine-tuning.

Using GPT-2 as the base model, the system generates product descriptions and refines them over multiple iterations by combining automatic evaluation metrics with manual human ratings. The project serves as a practical exploration of the core ideas behind RLHF-style systems.

Objective

The primary goal is to demonstrate that even simple feedback loops can meaningfully improve generative outputs when applied iteratively. Instead of modifying model weights directly, the system focuses on reward-guided selection and refinement of generated text.

This approach highlights how human judgment can complement automatic metrics, addressing their known limitations in capturing fluency, relevance, and real-world usefulness.

Methodology & Approach

  • Generate product descriptions using a pre-trained GPT-2 model
  • Evaluate generated text using BLEU and ROUGE-L metrics
  • Collect human ratings based on coherence, relevance, and readability
  • Normalize and combine metric scores with human feedback
  • Assign rewards and track improvement across iterations
  • Analyze trends to observe progressive quality enhancement

Evaluation Strategy

To balance objectivity and human judgment, a weighted reward function is used:

Combined Reward = 0.7 × (Human Score / 10) + 0.3 × (BLEU + ROUGE-L) / 2

This design prioritizes human feedback while still leveraging automatic metrics for consistency and comparability across iterations.

Key Features

  • Hybrid evaluation using both humans and automated metrics
  • Iterative improvement without retraining the base model
  • Visualization of reward and quality trends
  • Flexible framework adaptable to other text domains
  • Clear demonstration of human-in-the-loop AI systems

Dataset

The system operates on structured CSV datasets containing product titles, feature lists, and reference descriptions, similar to real-world e-commerce datasets such as Amazon product data.

Clarification on Reinforcement Learning

This project does not implement full reinforcement learning algorithms such as PPO or policy-gradient methods.

Instead, it demonstrates an RL-inspired iterative feedback framework where reward signals guide improvement through selection and evaluation, making it conceptually aligned with the foundations of RLHF.
