Overview

This project implements a production-ready wearable health monitoring system that predicts a user’s daily health score using multivariate sensor data collected from wearable devices.

Beyond model development, the project focuses heavily on automation, deployment, and monitoring, showcasing a complete ML lifecycle aligned with real-world MLOps practices.

Problem Statement

Wearable devices continuously generate large volumes of heterogeneous sensor data, including heart rate, sleep duration, activity levels, and stress indicators.

Transforming this raw data into actionable health insights requires scalable preprocessing pipelines, robust predictive models, and reliable production infrastructure.

End-to-End System Workflow

  • Ingest and preprocess wearable sensor data
  • Normalize features and prepare training datasets
  • Train a deep learning regression model for health score prediction
  • Serve predictions through an interactive Streamlit interface
  • Containerize the application using Docker
  • Automate training and deployment with Jenkins
  • Provision infrastructure using Terraform
  • Manage configuration using Puppet
  • Continuously monitor system health using Nagios

Machine Learning Pipeline

  • Feature scaling using StandardScaler
  • Deep learning regression model built with TensorFlow / Keras
  • Optimized inference through ONNX model export
  • Fast prediction using ONNX Runtime
  • Achieved an R² score of approximately 0.95

The model design balances predictive accuracy with inference efficiency, making it suitable for near real-time health monitoring.

MLOps & Automation

  • CI/CD pipeline using Jenkins for automated builds and deployments
  • Infrastructure provisioning using Terraform (IaC)
  • Configuration management with Puppet on Windows agents
  • Containerized application deployment using Docker
  • Automated testing and health checks

Monitoring & Observability

  • Application uptime monitoring on Streamlit service (port 8501)
  • CPU load and system resource monitoring
  • Host availability and service health checks
  • Alerting on failures or performance degradation
