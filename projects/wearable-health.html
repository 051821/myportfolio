Wearable Health Monitoring & Health Score Prediction

End-to-end ML + MLOps system for real-time health score prediction using wearable data

View GitHub

Overview

This project implements a production-style wearable health monitoring system that predicts an individual’s daily health score using sensor data from wearable devices. The system combines deep learning, automated CI/CD, infrastructure provisioning, configuration management, and continuous monitoring.

Problem Statement

Wearable devices generate large volumes of multivariate sensor data such as heart rate, sleep patterns, activity levels, and stress indicators. Converting this raw data into meaningful health insights requires scalable ML pipelines and reliable deployment infrastructure.

System Workflow

  • Collect and preprocess wearable sensor data
  • Train a deep learning regression model for health score prediction
  • Serve predictions via an interactive Streamlit application
  • Containerize the application using Docker
  • Automate training and deployment with Jenkins
  • Provision infrastructure using Terraform
  • Configure systems with Puppet
  • Continuously monitor system health using Nagios

Machine Learning Pipeline

  • Data normalization using StandardScaler
  • Deep learning regression model built with TensorFlow/Keras
  • Model export in both Keras and ONNX formats
  • Fast inference using ONNX runtime
  • Achieved an R² score of approximately 0.95

MLOps & Automation

  • CI/CD pipeline using Jenkins for automated builds and deployments
  • Infrastructure provisioning using Terraform (IaC)
  • Configuration management using Puppet on Windows agents
  • Containerized deployment using Docker
  • Automated health checks and monitoring

Monitoring & Observability

  • Application uptime monitoring on Streamlit port (8501)
  • CPU load monitoring of the host system
  • Host availability checks
  • Alerting on service or resource failures

Tech Stack

Python · TensorFlow / Keras · Streamlit · Docker · Jenkins · Terraform · Puppet · Nagios · ONNX · Pandas · Scikit-learn

What This Project Demonstrates

  • End-to-end ML system design
  • Integration of ML with DevOps & MLOps practices
  • Production-ready deployment and monitoring
  • Handling real-world sensor data pipelines
  • Applied ML in a healthcare context
