Text Summarization using Genetic Algorithm

Extractive text summarization using evolutionary optimization techniques

View GitHub

Overview

This project implements an extractive text summarization system using a Genetic Algorithm (GA). The goal is to automatically generate a concise summary from a large input document by selecting the most informative words through evolutionary optimization.

Problem Statement

Large text documents are time-consuming to read and analyze. Traditional summarization techniques often struggle to balance information retention and brevity.

Approach

  • Preprocess and tokenize input text
  • Represent candidate summaries as binary chromosomes
  • Initialize a population of summaries
  • Evaluate fitness using word overlap
  • Apply selection, crossover, and mutation
  • Evolve summaries across generations

Genetic Algorithm Design

  • Encoding: Binary inclusion of words
  • Selection: Roulette wheel selection
  • Crossover: Single-point crossover
  • Mutation: Bit-flip mutation
  • Fitness: Word overlap-based relevance scoring

Results

The system successfully reduced the original text length while preserving important content, demonstrating effective compression through evolutionary optimization.
